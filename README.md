# hospital-management-system-mad1
This Project will help hospitals to manage there all records. 

The app was built using Flask as the backend framework with a modular structure. Used html 
css for the frontend, Jinja2 for templating and sqlite to manage the database. This application 
allows users to manage their records. 

**Technologies and Frameworks Used**
Technology / Library Purpose 
Flask                        Core backend web framework
SQLAlchemy                   Object Relational Mapper for SQLite database 
Jinja2                       Template engine for rendering dynamic HTML pages 
Bootstrap 5                  Frontend styling and responsive design 
Chart.js                     To visualize trends such as activity vs. time 
Flask-Login                  User authentication and session management 
WTForms                      Frontend form validation 
SQLite                       Lightweight local database for storing user data 

**Architecture Overview:** 
● app.py – main Flask application entry point 
● /models – database models using SQLAlchemy 
● /routes – Flask Blueprints for user and activity routes 
● /templates – Jinja2 HTML templates 
● /static – CSS
